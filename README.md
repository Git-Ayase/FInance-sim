# キャッシュフロー

バイト代・カード請求・大きい買い物から、口座残高の今後を日付ごとに予測するアプリです。
データはパスワードで暗号化して、ブラウザの中だけに保存します。サーバーは使いません。

## できること

- **バイト**：時給 × 労働時間（月ごとに変更可）− 控除 ＋ 交通費で支給額を出し、給料日に入金。年間の給与収入と上限の目安も表示
- **カード・請求**：カードごとの締め日・支払日・支払月を登録。確定した請求額と、毎月の見込み額を入力
- **大きい買い物**：金額を入れると「カード × 引き落とし日」の組み合わせごとに最低残高を比較。引き落とし日を選ぶと、その日に払うために買う期間を表示。分割払いと手数料にも対応
- **概要**：残高の推移グラフ、月ごとの集計、入出金の明細、最低残高の日。CSV で書き出し可

## 公開先

- URL：https://finance.ayase-tech.com/
- GitHub Pages（`main` ブランチの直下）から配信。独自ドメインは `CNAME` ファイルで指定
- DNS：`ayase-tech.com` の DNS に `finance` → `git-ayase.github.io` の CNAME レコードを追加
- `main` に push すると数分で反映されます

> 端末ごとにデータは別です。スマホと PC の両方で使うときは「設定 → バックアップ」で書き出し、もう一方で読み込みます。

## 安全性のしくみ

| 項目 | 内容 |
|---|---|
| ログイン | パスワードから PBKDF2-HMAC-SHA256（600,000 回、ランダムな 16 バイトのソルト）で鍵を作り、データを復号できたらログイン成功。パスワード自体はどこにも保存しない |
| 暗号化 | AES-256-GCM。保存のたびに新しい IV を使い、改ざんされると復号に失敗する |
| 鍵の扱い | 鍵は取り出せない `CryptoKey` としてメモリ上にだけ置き、ロック時に破棄 |
| 自動ロック | 一定時間操作がないとロック（初期値 5 分、設定で変更可） |
| 総当たり対策 | 間違えるたびに待ち時間を延ばす。本当の防御は PBKDF2 の重さと長いパスワード |
| 通信 | CSP で外部への通信・外部スクリプト・フォント読み込みを禁止（`connect-src 'none'`） |
| 検索避け | `robots.txt` と `noindex` |

**注意**

- パスワードを忘れると復元できません。バックアップも同じパスワードがないと開けません
- CSV の書き出しは暗号化されません
- GitHub Pages ではレスポンスヘッダーを設定できないため、CSP は `<meta>` で指定しています（`frame-ancestors` は効きません）
- 端末自体にマルウェアがある場合や、ロック解除中の画面はこのアプリでは守れません

## 開発

```sh
node tests/model.test.mjs   # 計算ロジックのテスト
python3 -m http.server 8000 # http://localhost:8000 で確認
```

`js/model.js` が計算、`js/crypto.js` が暗号化、`js/app.js` が画面です。ビルドは不要です。
