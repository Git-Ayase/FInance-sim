# キャッシュフロー

バイト代・カード請求・大きい買い物から、口座残高の今後を日付ごとに予測するアプリです。
データはパスワードで暗号化して、ブラウザの中だけに保存します。サーバーは使いません。

## できること

- **バイト**：シフトをカレンダーで登録（出勤・退勤を H:MM で入力、いつでも編集可）。休んだ日と早退した日だけ記録すると、その分を引いて支給額を計算。シフトが 8 時間を超えると 1 時間の休憩を引き、1 日の上限は 7 時間（どちらも設定で変更可）。シフトがない先の月は標準の労働時間で見込む。年間の給与収入と上限の目安も表示
- **カード・請求**：カードごとの締め日・支払日・支払月を登録。確定した請求額と、毎月の見込み額を入力
- **口座・入金**：銀行口座を複数登録し、口座ごとに残高を計算（カードの引き落とし口座・バイトの振込先・ローン・入金先を口座ごとに指定）。一番少なくなる口座の最低残高を警告。お小遣いなどバイト以外の入金（毎月／1回だけ）も登録
- **サブスク**：毎月・毎年の課金を登録し、カード払いなら締め日・支払日から引き落とし日を計算、口座払いも選択可。月あたり・年あたりの合計を表示
- **ローン**：毎月の返済額・引き落とし日・初回の月・返済回数（ボーナス月の加算も可）を入れると、口座からの引き落としとして計算。残りの回数・金額と完済予定を表示
- **大きい買い物**：金額を入れると「カード × 引き落とし日」の組み合わせごとに最低残高を比較。引き落とし日を選ぶと、その日に払うために買う期間を表示。分割払いと手数料にも対応
- **概要**：残高の推移グラフ、月ごとの集計、入出金の明細、最低残高の日。CSV で書き出し可

## 公開先

- URL：https://finance.ayase-tech.com/
- GitHub Pages（`main` ブランチの直下）から配信。独自ドメインは `CNAME` ファイルで指定
- DNS：`ayase-tech.com` の DNS に `finance` → `git-ayase.github.io` の CNAME レコードを追加
- `main` に push すると数分で反映されます

## 端末間の同期

暗号化したデータを、自分の**非公開リポジトリ**に 1 ファイルとして保存し、スマホと PC などで同じデータを使います（GitHub API を直接呼ぶので、サーバーは不要です）。

1. GitHub で非公開のリポジトリを作る（例：`finance-sim-data`、空のままで OK）
2. Settings → Developer settings → Personal access tokens → **Fine-grained tokens** でトークンを作る
   - Repository access：Only select repositories → `finance-sim-data` だけ
   - Permissions：**Contents → Read and write**
3. アプリの「設定 → 端末間の同期」にリポジトリとトークンを入れて「接続して同期」
4. ほかの端末では、ロック画面の「別の端末で使っているデータを読み込む」から、同じリポジトリ・トークン・パスワードを入れる

- 変更は数秒後に自動で送信し、開き直したときと開いている間は 45 秒ごとに取り込みます
- 両方の端末で同時に変更があったときは、どちらを残すか選ぶ画面が出ます
- 別の端末でパスワードを変えると、次の同期で新しいパスワードを聞かれます
- 公開リポジトリは同期先に使えないようにしています


## 安全性のしくみ

| 項目 | 内容 |
|---|---|
| ログイン | パスワードから PBKDF2-HMAC-SHA256（600,000 回、ランダムな 16 バイトのソルト）で鍵を作り、データを復号できたらログイン成功。パスワード自体はどこにも保存しない |
| 暗号化 | AES-256-GCM。保存のたびに新しい IV を使い、改ざんされると復号に失敗する |
| 鍵の扱い | 鍵は取り出せない `CryptoKey` としてメモリ上にだけ置き、ロック時に破棄 |
| 自動ロック | 一定時間操作がないとロック（初期値 5 分、設定で変更可） |
| 総当たり対策 | 間違えるたびに待ち時間を延ばす。本当の防御は PBKDF2 の重さと長いパスワード |
| 通信 | CSP で外部スクリプト・フォントを禁止し、通信先は同期用の `api.github.com` だけに制限 |
| 同期 | GitHub に送るのは暗号文だけ。同期先は非公開リポジトリに限定。トークンは端末内に暗号化して保存し、同期先のファイルには含めない |
| 検索避け | `robots.txt` と `noindex` |

**注意**

- パスワードを忘れると復元できません。バックアップも同じパスワードがないと開けません
- CSV の書き出しは暗号化されません
- GitHub Pages ではレスポンスヘッダーを設定できないため、CSP は `<meta>` で指定しています（`frame-ancestors` は効きません）
- 端末自体にマルウェアがある場合や、ロック解除中の画面はこのアプリでは守れません

## 開発

```sh
node tests/model.test.mjs   # 計算ロジックのテスト
python3 -m http.server 8000 # http://localhost:8000 で確認
```

`js/model.js` が計算、`js/crypto.js` が暗号化、`js/app.js` が画面です。ビルドは不要です。
